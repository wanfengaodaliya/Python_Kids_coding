# TabBar Icon Sources

The SVG source icons in this folder were downloaded from Iconify's Lucide collection:

- `levels.svg`: `lucide:map`
- `chat.svg`: `lucide:bot-message-square`
- `records.svg`: `lucide:calendar-check`
- `settings.svg`: `lucide:settings`

Lucide is an open-source icon library. The PNG files in `../` are local 81x81 transparent tabBar assets generated for this mini program's normal color `#6b7280` and selected color `#4A90E2`.
